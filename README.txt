=====================================
  日々の実践チェックリスト
  使い方ガイド
=====================================

■ はじめに
このアプリは、毎日の実践項目（30項目）の達成状況を記録し、
振り返りを残すためのツールです。
インターネットブラウザだけで動作し、インストール不要です。

■ 使い方

【PC版】
1. index.html をブラウザで開きます
2. 上部のグリッドで、各項目の日付セルをクリック
   - 1回目: ◎（実施できた）
   - 2回目: ×（実施できなかった）
   - 3回目: 空白に戻る
3. 項目名をクリックすると編集できます
4. 下部に日別の振り返り欄があります（200字以内）
5. 実施率は自動計算されます

【スマホ版】
1. スマホのブラウザでindex.htmlを開きます
2. 1日分ずつ表示されます
3. 左右の矢印（またはスワイプ）で日付を切り替え
4. 各項目をタップして ◎ → × → 空白 を切り替え
5. 下部に振り返り入力欄があります

【ホーム画面に追加（スマホ）】
- iPhone: Safari で開く → 共有ボタン → 「ホーム画面に追加」
- Android: Chrome で開く → メニュー → 「ホーム画面に追加」
※ アプリのように使えます

■ 月の切り替え
- ヘッダーの < > ボタンで前月・翌月に移動できます

■ Excel出力
- 「Excel出力」ボタンで当月データをダウンロード
  - Sheet1: チェックデータ＋実施率
  - Sheet2: 日々の振り返り
- ファイル名: 実践チェックリスト_YYYY年MM月.xlsx

■ データの保存
- データはブラウザのLocalStorageに自動保存されます
- ブラウザのデータを消去すると記録も消えます
- 月末にExcel出力でバックアップをおすすめします

■ 注意事項
- 初回はインターネット接続が必要です
  （Excel出力ライブラリの読み込みのため）
- 2回目以降はオフラインでも使用可能です
- 別のブラウザやデバイスにはデータは共有されません
